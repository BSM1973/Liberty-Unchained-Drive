# v0.5 Spectral Mastering Engine

Linear phase is a complementary 129-tap Blackman-window FIR per boundary, using sparse base-rate taps at oversampled rates, with 64 base-sample group delay. Low-frequency transition bands are broad; it is not a steep mastering crossover. Fixed latency increases by 64 samples in all modes; actual host PDC and oversampling phase alignment remain to be measured. Delta subtracts delayed original signal from processed signal, with a 5 ms fade. IIR oversampling phase response means the residual may include filter phase effects. Linked RMS shares correction in stereo/M-S when LINK is enabled; perceptual compensation is not implemented. K-weighted momentary 400 ms and short-term 3 s monitoring; no integrated gating or LRA. True peak is estimated from 4x FIR interpolation, not certified. Spectral test reports controlled-tone in-band THD and nonharmonic residual (aliasing proxy) for eight static curves at five real JUCE oversampling factors, not full-chain aliasing or live THD. Core benchmarks process 5 seconds per engine and report wall time, not realtime host certification. Preset listening and host tests require external validation. No visual rendering was performed.
